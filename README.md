# Keren Amar | מעקב טיפולים והכנסות

כלי מהיר, ידידותי למגע (iPad/iPhone), לתיעוד טיפולי ציפורניים מול טיפולי
פנים ברגע שהם מתבצעים — בלי יומן תורים ובלי ניהול לקוחות — עם המטרה
לשקף את היחס בין הקטגוריות ולדחוף צמיחה בטיפולי פנים. Next.js (App
Router) + TypeScript + Tailwind CSS.

## מקומי לחלוטין — בלי התחברות, בלי שרת

**אין login, אין חשבון, ואין Supabase.** כל הנתונים (מחירון, תיעודי
טיפולים, מוצרים, הוצאות, יעד שבועי) נשמרים ב-`localStorage` של הדפדפן
בלבד, במכשיר הזה. פתיחה ראשונה של האפליקציה מזרעת מחירון טיפולים
ריאלי (בלי תיעודי טיפולים לדוגמה) ומאז כל פעולה נשמרת ישירות במכשיר —
בלי בקשות רשת, בלי חשבון, בלי סיסמה.

גיבוי/שחזור ידניים (ייצוא/ייבוא קובץ JSON) זמינים במסך "עוד" ⚙️.
סנכרון בין מכשירים עם קוד זיווג (בהשראת `tochnit-hachlama`) הוא יעד
עתידי שעדיין לא מומש — כרגע יש רק את הגיבוי הידני.

## הרצה מקומית

```bash
npm install
npm run dev
```

האפליקציה עולה על [http://localhost:3000](http://localhost:3000) —
ישר לדשבורד, בלי מסך התחברות.

## פריסה (Deploy)

הפרויקט מוכן לפריסה בכל שירות שתומך ב-Next.js (למשל Vercel/Netlify) —
אין משתני סביבה נדרשים, כי כל הנתונים נשארים בדפדפן של המשתמשת.

⚠️ מכיוון שהנתונים חיים ב-`localStorage` בלבד, ניקוי נתוני האתר/דפדפן
או מעבר למכשיר אחר מוחקים/לא מעבירים אותם — לכן חשוב להשתמש בייצוא
הגיבוי במסך "עוד" מדי פעם.

## הלוגו

הלוגו הרשמי חולץ מקובץ ה-PDF שסופק וגזור לשלושה קבצים ב-`public/`:

- `public/logo-full.png` — הלוגו המלא (מונוגרמה + "KEREN AMAR" + התגית).
- `public/logo-mark.png` — המונוגרמה "ka" בלבד, מוצגת בהדר של כל המסכים.
- `public/favicon.png` — גרסה ריבועית עם רקע בז' של המערכת, לטאב הדפדפן
  ולאייקון PWA.

אם בעתיד יתקבל קובץ וקטורי (SVG/AI) מקורי מהמעצבת, אפשר להחליף את
שלושת הקבצים באיכות וקטורית מלאה — יש רק לעדכן את הסיומת בהפניות
ב-`src/app/layout.tsx`, `src/components/layout/Header.tsx`,
`src/app/(app)/page.tsx` ו-`public/manifest.json` אם משנים סיומת קובץ.

## מבנה הנתונים

כל הנתונים חיים במבנה `Store` אחד (ראו `src/lib/local/store.ts`) עם
הטבלאות `treatments`, `treatment_log`, `product_sales`,
`expense_categories`, `expenses`, `weekly_goals` — נשמרים כאובייקט JSON
יחיד תחת מפתח `keren_amar_store_v1` ב-`localStorage`
(`src/lib/local/browserStore.ts`). הגישה לנתונים מהעמודים/הרכיבים
עוברת דרך `src/lib/local/browserClient.ts`, שחושף API בסגנון
Supabase-JS (`.from(table).select()/insert()/update()/delete()`) כדי
ששכבת התצוגה תישאר זהה בין local ל-backend עתידי, בלי לדרוש שרת בפועל.

אין יומן תורים ואין ניהול לקוחות — `treatment_log` נוצרת ישירות כשלוחצים
על טיפול ב"💅 ציפורניים" או "✨ טיפולי פנים" בדף הבית וממלאים מחיר
ואמצעי תשלום ותאריך (בלי שעה — רק תאריך); אין שיוך ללקוחה ואין תזמון
מראש.

## טכנולוגיה

- Next.js 16 (App Router, Client Components) + TypeScript + Tailwind CSS v4
- אחסון מקומי (`localStorage`) עם שכבת client בסגנון Supabase-JS — ראו
  `src/lib/local/`
- recharts לגרפים, lucide-react לאייקונים, date-fns לתאריכים
- עברית מלאה, RTL, Mobile-First
